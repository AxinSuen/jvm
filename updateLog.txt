# 更新日志

## v0.3.0
**发布日期：2026-05-08**

🚀 **优化与修复**
- **多源下载架构解耦**：彻底重构 API 解析逻辑，引入统一的 JDKProvider 接口。原生支持 Adoptium (Temurin) 和 Azul Zulu 发行商 API。新增兜底通用解析器，支持无缝接入自定义的私有分发节点。
- **动态源切换指令**：新增 jvm source [url|name] 命令，可一键在不同 JDK 发行商（如 zulu、adoptium）或自定义 URL 之间来回切换，支持持久化配置。
- **底层软链接机制替换**：将 jvm use 阶段创建软链接的底层指令从 mklink /D (符号链接) 全面更改为 mklink /J (目录联接)，彻底绕过 Windows 家庭版等系统中严苛的特权限制，实现免配置下的 100% 稳定运行。
- **联接目标解析异常修复**：修复因 Go 语言原生 EvalSymlinks 方法无法解析 Windows 目录联接（Junction）指向，从而导致 jvm ls 丢失当前激活版本 * 号标识的 Bug。已用更底层的 os.Readlink 重写判定逻辑。
- **直观的术语重构**：为降低用户理解成本，将配置文件及控制台交互中的 symlink 概念全面重命名为更直观的 javahome，并同步更新修改命令为 jvm javahome。
- **增强前置路径容错**：在执行目录联接前自动检查并静默创建父目录，防止用户因误删物理空文件夹（如 C:\Program Files\Java）而导致的无法创建快捷方式错误。
- **本地化与交互优化**：精简了 setup 和 uninstall 的成功提示；将所有提权操作后的“按回车键退出”交互收拢并统一提示语风格；将全局提示语重新对齐为中文。
- **更新说明文档**：同步更正 README.md、GITHUB_INTRO.md，更新了版本特性并移除了过时的旧配置说明。

## v0.2.6
**发布日期：2026-05-07**

🚀 **优化与修复**
- **快捷序号映射切换**：jvm ls 命令现在会自动为每一个已安装的版本分配简短的序号。您现在可以直接通过输入序号来进行版本切换（jvm use 1）或卸载（jvm uninstall 1），大幅降低了输入繁琐版本号的成本。
- **动态寻址校验当前版本**：重构了获取当前活动版本的底层逻辑。不再依赖配置文件缓存，而是直接读取当前系统中生效的物理软链接目标。确保 jvm ls 显示的 * 号在任何极端情况下都 100% 准确，并移除了内部代码中多余的历史遗留字段。
- **修复创建软连接失败及报错闪退**：彻底移除了操作软链接时对 PowerShell 命令的依赖，全面改用原生底层 cmd，根治了路径转义失效、目标内容被错误清空等极其隐蔽的 Bug。
- **修复切换版本时独立窗口一闪而过**：为涉及提权执行的命令全局增加了等待拦截。当 UAC 弹窗发生报错或执行完毕时，窗口会明确提示“请按回车键关闭此窗口”，避免出错时用户无法查看错误日志。
- **修复环境变量 Path 写入后失效**：解决了通过 install.bat 将 %JAVA_HOME%\bin 注入注册表时由于类型解析导致指令不生效的问题，已全面改为注入真实可靠的物理绝对路径，并同步完善了卸载脚本的深度清理逻辑。

## v0.2.5
**发布日期：2026-05-07**

🚀 **优化与修复**
- **修复 UAC 权限死循环**：解决了在某些 Windows 环境下（如禁用了 Server 服务），即使授予管理员权限，安装和卸载脚本仍会反复弹出授权窗口的问题。
- **更可靠的权限检测**：将脚本中的管理员权限检测命令从 net session 迁移至更通用的 fltmc，提升了在各类精简版/定制版系统中的兼容性。
- **引入防死循环标志位**：在脚本提权重新运行时自动添加 --elevated 参数。脚本在启动时若检测到该参数，将直接跳过权限检查进入执行逻辑，从逻辑上彻底杜绝无限弹窗循环。
